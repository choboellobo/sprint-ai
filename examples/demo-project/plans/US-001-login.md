## Story
ID: US-001
Como usuario, quiero iniciar sesión para acceder a mi cuenta.

## Areas
front, back

## Acceptance criteria
- [ ] Dado que tengo una cuenta, cuando introduzco credenciales válidas, entonces entro en mi espacio.
- [ ] Dado que las credenciales no son válidas, cuando intento entrar, entonces veo un error y permanezco fuera.

## Verification
- [x] Entrar con credenciales válidas — navegador, manual. Se muestra el espacio personal.
- [x] Rechazar credenciales inválidas — navegador, manual. Se muestra el error y no se inicia sesión.
